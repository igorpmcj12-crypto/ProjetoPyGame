## História
Um jovem portador de um dispositivo alienígena precisa atravessar uma zona perigosa, destruindo inimigos enquanto tenta conseguir a maior pontuação possível. O jogo usa uma temática de transformação alienígena com identidade visual própria.

## Tecnologias utilizadas
- Python
- Pygame
- pyttsx3
- Git e GitHub

## V3 - Áudio, efeitos e transformações
- Música de fundo em loop.
- Som de soco, disparo, transformação, impacto, ponto e morte.
- Efeito visual de transformação.
- Menu Omnitrix para escolher o herói, Chamas ou Bola de Canhão.
- Ataque de soco do herói.
- Ataque/ação de Chamas e rolamento da Bola de Canhão.
- Animações de caminhar, correr, pular, agachar, atacar, rolar, morrer e transformar.

## Controles
- A / D ou setas: movimentar no eixo X.
- Shift: correr.
- W / seta para cima: pular.
- S / seta para baixo: agachar.
- Z ou botão esquerdo: atacar.
- G: abrir/fechar o Omnitrix.
- 1: Chamas.
- 2: Bola de Canhão.
- 0: voltar ao herói.
- Space: pausar/continuar.
- ESC: fechar completamente.

## Estrutura
- `main.py`: arquivo principal do jogo.
- `Recursos/trabalho.py`: funções úteis importadas pelo principal.
- `bases/`: imagens, sons, fontes e ícones.
- `log.dat`: registro das partidas.

## Execução
1. Instale Python.
2. Instale as dependências com `py -m pip install -r requirements.txt`.
3. Execute com `python main.py`.
